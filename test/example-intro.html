OFD 解析、渲染与双向转换

四个可以单独使用的模块：核心引擎把 OFD 解析成 SVG，预览器负责阅读，ofd2pdf 导出 PDF，pdf2ofd 把 PDF 转回 OFD。演示文件全部来自本机，不上传。

OFD → ofd-core 解析渲染 → viewer 阅读 → ofd2pdf 导出 → PDF
PDF → pdf2ofd 转换 → OFD

ofd-core 核心引擎

browser + node ≥ 19

把 OFD 包解析成 SVG 页面，提供页数、尺寸、元信息、签名校验与字体配置。加载时只读目录结构，页面内容在首次渲染时再解析。

产物build/ofd/ofd.min.js
全局名OFD
npm 包ofd-core
运行时依赖无
渲染预览 样本来自 test/ofdFile/

选择仓库样本、本地文件或填写路径后点「加载」

使用代码

npm 安装与 Node 调用 Node ≥19 / load / renderPageToString

const fs = require('fs');
const OFD = require('ofd-core');

(async () => {

  fs.writeFileSync('page.svg', svg);

ofd2pdf 导出 PDF

browser + node ≥ 19

复用引擎的 SVG 输出，逐页拼成 PDF 内容流。纯前端运行，不依赖后端服务。

产物build/ofd2pdf/ofd2pdf.js
全局名TOPDF
npm 包ofd2pdf
运行时依赖ofd-core
转换并下载 转换在本机完成，不上传

使用代码

npm 安装与 Node 调用 Node ≥19 / ofdToPdf 
npm install ofd2pdf ofd-core

const fs = require('fs');
const OFD = require('ofd-core');
const TOPDF = require('ofd2pdf');

(async () => {
  const ofd = await OFD.load(new Uint8Array(fs.readFileSync('document.ofd')));
  const pdf = await TOPDF.ofdToPdf(ofd, { title: 'document' });
  fs.writeFileSync('document.pdf', pdf);
})();
整份转换与单页转换 ofdToPdf / svgToPdf 
<script src="build/ofd/ofd.min.js"></script>
<script src="build/ofd2pdf/ofd2pdf.js"></script>
<script type="module">
  // 必须先加载 ofd.min.js，TOPDF 从全局 OFD 取渲染结果
  const ofd = await OFD.load('document.ofd');

  const pdf = await TOPDF.ofdToPdf(ofd, {
    title: 'document',
    author: 'ofd-core',
    renderOpts: { width: 1200 },
    onProgress: (done, total) => console.log(done + '/' + total),
  });
  const url = URL.createObjectURL(new Blob([pdf], { type: 'application/pdf' }));
  const a = Object.assign(document.createElement('a'), {
    href: url,
    download: 'document.pdf',
  });
  a.click();
  URL.revokeObjectURL(url);

  const svg = await OFD.renderPageToString(ofd, 0);
  const single = await TOPDF.svgToPdf(svg, 210, 297, { title: 'single' });
</script>

pdf2ofd 反向转换

node ≥ 18

把 PDF 转成 OFD 包，保留矢量路径、文本、图像与渐变。依赖 Node 文件系统与 pdf.js，只在 Node 或命令行运行。

产物build/pdf2ofd/pdf2ofd.js
全局名无（CommonJS）
npm 包pdf2ofd
运行时依赖pdfjs-dist ≥ 4

使用代码

npm 安装、命令行与批量 convert / convertMany / version 
npm install pdf2ofd pdfjs-dist
npx pdf2ofd input.pdf output.ofd
npx pdf2ofd -q input.pdf out/result.ofd

# 仓库内直接用构建产物
node build/pdf2ofd/pdf2ofd.js input.pdf output.ofd

const { convert, convertMany, version } = require('pdf2ofd');
// convertMany / version 只在 npm 包入口导出

(async () => {
  const stats = await convert('input.pdf', 'output.ofd', {
    onProgress: (done, total) => console.log(done + '/' + total),
    quiet: true,
  });
  // stats: { pages, fonts, images, bytes }

  await convertMany([
    { from: 'a.pdf', to: 'out/a.ofd' },
    'b.pdf',
  ], { quiet: true });

  console.log(version);
})();

运行环境与已知限制

浏览器
Chrome / Edge 80+ Firefox 113+ Safari 16.4+

ZIP 解压依赖原生 DecompressionStream，旧版浏览器无法打开 OFD。

Node
ofd-core / ofd2pdf：Node ≥19 pdf2ofd：Node ≥18

ofd-core 与 ofd2pdf 需要全局 crypto.getRandomValues；pdf2ofd 仅支持 Node。

加载方式
HTTP(S)

预览器用 fetch 读取文件，file:// 协议下无法自动加载，手选文件仍可用。

字体
可选

外部字体放 font/，所在目录需要被服务器输出列表才会生效，失败时回退内嵌字体与系统字体栈。

验签边界
未做证书链 未做吊销 未做时间戳

只验证 SM2 签名值、文件摘要与有效期，不判断签发者是否被信任。

ofd2pdf
beta

演示级转换，不保证与 OFD 原件逐像素一致，正式使用前请人工核对输出。

pdf2ofd
浏览器不可用

依赖 Node 文件系统与 pdf.js，只能在 Node 或 CLI 运行。

安全
未审计

已限制解压体积、图像像素与 URL 协议，但未经过专业安全审计。
