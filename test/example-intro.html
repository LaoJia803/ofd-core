3函数调用流程
从加载到渲染的完整数据流

加载阶段

OFD.load(source)
  ├─ 读取文件数据 (fetch / Blob / ArrayBuffer → Uint8Array)
  ├─ readZip(data)                        → ZIP 句柄
  └─ parseOFD(zip)
       └─ parseDocument(zip)
            ├─ readEntryText(zip, 'OFD.xml')     → 解析文档信息
            ├─ readEntryText(zip, docPath)       → 解析 Document.xml
            │    ├─ parseBox()                   → 页面物理尺寸
            │    ├─ parseRes(publicRes)          → 公共资源（字体/颜色/图片引用）
            │    ├─ parseRes(documentRes)        → 文档资源
            │    ├─ parseSignatures()             → 签名与印章（含 Seal.esl / SignedValue.dat）
             │    └─ parseAnnotations()           → 注解（印章 + 高亮/下划线等文本注释）
             └─ 返回 { info, document, zip }

渲染阶段

OFD.renderPageToString(ofd, pageIndex, opts)
  ├─ ensurePageParsed(ofd, pageIndex)        → 命中缓存或 parsePage()
  │    └─ parsePage(pagePath, zip)
  │         ├─ readEntryText(zip, pagePath)
  │         ├─ parseXml() → parseBox()       → 页面尺寸
  │         └─ parseLayer() × N              → 图层对象列表
  │
  ├─ 收集模板图层
  │    └─ getTemplateLayers(tpl, ofd) × N
  │
  ├─ 图像预取（并行）
  │    └─ Promise.all([ ensureImageDataUrl(mm), ... ])
  │
  ├─ 字体预取（未映射字体从 font/ 目录加载）
  │    └─ Promise.all([ ensureFontLoaded(name), ... ])
  │
  ├─ 逐图层渲染对象
  │    └─ renderObject(obj, res)
  │         ├─ renderPathObject()            → SVG <path>
  │         ├─ renderTextObject()            → SVG <text>/<tspan>
  │         └─ renderImageObject()           → SVG <image>
  │
  ├─ 渲染本页的印章与注释
  │    ├─ renderStamp(stamp, stampIdx) × N    → 印章（矢量印章直接遍历 sealOfd 图层渲染）
  │    └─ renderAnnot(annot) × N              → 文本注释（高亮/下划线/删除线/画笔/矩形）
  │
  └─ 拼装 <svg> 字符串返回

签名验证阶段

OFD.verifySignature(ofd, index)
  ├─ 直接读取 ofd.document.signatures[index]  → 签名项（含 references 摘要）
  └─ 逐个 references 项校验
       ├─ readEntry(zip, fileRef)             → 原始文件字节
       ├─ hashBytes(data, checkMethod)        → 计算摘要（SM3 内置 / SHA-* 走 WebCrypto）
       └─ bytesEqual(digest, base64ToBytes(checkValue)) → 比对
  └─ 返回 { valid, status: 'valid'|'invalid'|'unknown', message }

6关键内部机制

ZIP 读取

自实现 ZIP 解析（Store / Deflate），readEntry 按名取二进制，readEntryText 取文本。

SM3 哈希

纯 JS 实现 SM3 国密哈希算法，用于数字签名摘要校验。

ASN.1 解析

解析证书（collectCerts）、签名值（extractSignatureValue）、签章名称（extractSealName，从 SignedValue.dat 的 UTF8String 提取）。

印章图片

extractSealPicture 从 ESL/DAT 流提取 PNG/JPEG（带 magic bytes 回退）；picture.type='ofd' 时为内嵌 OFD 矢量印章，走 parseSealOfd 递归解析。

印章文字

椭圆弧上排布签章文字（如「重庆市税务局」沿下弧），顶部弧与文字遮挡问题已在渲染中校正。

文本渲染

TextCode 逐字定位：可合并的文本输出为单 tspan（x/y 值列表保留每字符绝对坐标）；readDirection=90/270 时逐字符 rotate()。

字体映射

mapFontFamily 按中文字符串包含关系匹配（如「小标宋体」含「宋」→ Song 系）；未映射字体从 font/ 目录通过 FontFace API 动态加载。

注释渲染

parseAnnotations 解析 Annots/Annotations.xml（印章 / 高亮 / 路径 / 水印 / 链接）；Appearance 作为完整页块按 PathObject、TextObject、ImageObject、CompositeObject 通用渲染，BlendMode=Darken → mix-blend-mode: darken。Link 注释输出可点击热点，仅放行 http(s) 外链。

7注意事项
  • 依赖顺序：必须先加载 ofd.js，再加载依赖它的模块（如 ofd2pdf.js）
  • ZIP 解压：浏览器依赖 DecompressionStream（Chrome 80+），Node 依赖内置 zlib
  • 坐标系统：Y 轴向下，不翻转；页面尺寸单位为毫米（mm）
  • 懒解析 + 缓存：load() 只解析文档元信息与签名/注解，每页 XML 在首次渲染时才解析，结果缓存到页面对象的 _parsed
  • 文本坐标：CTM 变换分支使用局部坐标，非 CTM 分支按 HScale 修正 X 坐标
  • 签章验证：失败不阻塞渲染（解析异常被捕获并忽略）
  • 印章去重：签名中的 SignatureInFile 注解可能产生重复印章，渲染时按 Subtype 去重
  • 注释渲染：文本注释复用 stamps 数组（标记 isAnnot），不挂 data-stamp-idx，不影响盖章点击逻辑
