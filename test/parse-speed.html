口径说明

四个指标

  • 加载：读字节 + ZIP 解压 + 文档结构（Document.xml）解析。
  • 页面解析：加载 + 逐页解析 Page XML 为图形对象模型，不含 SVG。
  • 首屏：加载 + 首页解析 + 首页 SVG 生成，即打开文档看到第一页的耗时。
  • 全文档：加载 + 所有页解析 + 所有页 SVG 生成。

测量方式

  • 每个指标都使用全新的文档实例，避免 SVG 缓存和页面解析缓存混入。
  • 每个样本独立跑 5 次，取中位数，降低 JIT 与系统抖动影响。
  • Node 环境不涉及 DOM 挂载、字体栅格化和浏览器绘制，因此数字低于浏览器里的完整渲染。
  • 样本来自 test/ofdFile/，覆盖国标结构样例、发票、大页数文档与文字密集型文档。
